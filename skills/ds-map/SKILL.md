# Карта дизайн-системы

Один раз читаем файл Figma с системой и записываем в короткие текстовые файлы то, что нужно для сборки экранов. Дальше сборка идёт по карте, а в Figma агент ходит за конкретными компонентами.

## Что нужно

- Ссылка на файл Figma с системой. Нет ссылки — спроси.
- MCP Figma. Вызови `whoami`. Инструментов нет или план не позволяет менять файлы — остановись и скажи, чего не хватает.

## Порядок

1. `get_metadata` по файлу: страницы и верхние узлы. Найди страницы с основой (цвета, текст), с компонентами и с экранами. Страницы со старыми версиями, черновиками и архивом (v1, Legacy, «Черновики», «Архив» и похожие) не читай: только перечисли их в `figma.md` списком «Не открывать».
2. Для каждой страницы компонентов — `get_metadata` глубже: наборы компонентов и одиночные компоненты, их варианты и свойства.
3. `get_variable_defs` — переменные: цвета, отступы, скругления. Стили текста.
4. Страница экранов: секции-паттерны, их описание и экраны внутри. Для каждого паттерна посмотри один экран: какие компоненты и в каком порядке сверху вниз. Размер рамки экрана запиши в правила.
5. Запиши файлы:
   - `ds/figma.md` — ссылка на файл, fileKey, названия и id страниц, куда класть новые экраны, список «Не открывать».
   - `ds/INDEX.md` — по разделам. Одна строка — один компонент: имя, id узла, варианты (свойство: значения), текстовые свойства, для чего нужен. «Для чего нужен» бери из описания компонента в Figma.
   - `ds/tokens.md` — цвета (имя переменной и значение), стили текста (имя, размер и интерлиньяж, начертание), отступы, скругления.
   - `ds/patterns.md` — по паттерну на раздел: когда применять, блоки сверху вниз (компонент и вариант из `INDEX.md`), правила из описания секции, экраны-примеры в файле с id. Примеры — чтобы сверить, а не копировать.
   - `ds/playbook.md` — заголовок «Правила сборки» и до десяти стартовых правил, которые видны из системы, описаний компонентов и паттернов: размер экрана, отступы по краям, где главная кнопка, какой шрифт.
6. Проверь: каждое имя и id в `INDEX.md` и `patterns.md` есть в файле, ничего не придумано.
7. Отчитайся: сколько компонентов и вариантов, сколько переменных и стилей, какие паттерны, что прочитать не удалось.

## Правила

- Этот скилл только читает Figma. Ничего в файле не меняй.
- В карту — только то, что нужно для сборки экранов. Служебные компоненты пометь, а не прячь.

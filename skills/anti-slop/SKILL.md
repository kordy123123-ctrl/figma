# Проверка экрана

1. `get_metadata` рамки. Каждый блок должен быть экземпляром компонента из `ds/INDEX.md`. Найди отсоединённые экземпляры и элементы, нарисованные поверх.
2. Цвета, отступы и стили текста — только переменные и стили из `ds/tokens.md`. Шрифт не подменён.
3. Порядок блоков совпадает с паттерном из `ds/patterns.md`.
4. Тексты без выдуманных обещаний, восклицаний и эмодзи. Суммы, имена и подписи правдоподобные, как в настоящем продукте.
5. Сверь экран с `ds/playbook.md` по пунктам.
6. Найденное исправь через `use_figma`, сделай `get_screenshot` и перечисли исправления, по строке на каждое. Ошибка повторяется — допиши правило в `ds/playbook.md`.
